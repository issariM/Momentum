# Momentum — Current Context

## What it is
PWA habit tracker with coin-reward system. Vanilla JS, localStorage only, no backend.

## Live URLs
- App: https://habittrackerfromclaudecode.netlify.app
- GitHub: https://github.com/issariM/Momentum
- Deploy: push to `main` → Netlify auto-deploys (~1 min)

## File Structure
```
index.html          — all UI markup
script.js           — all app logic (vanilla JS, localStorage)
styles.css          — design system + component styles
sw.js               — service worker (cache-first, offline)
manifest.webmanifest
icon-192.png / icon-512.png / icon.svg
```
